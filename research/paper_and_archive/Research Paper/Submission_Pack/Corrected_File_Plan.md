# Corrected publication file plan

The supplied list is a useful starting point. The main correction is to distinguish actual journal requirements, evidence needed for the chosen claims, and optional documents. More files or more baseline models do not by themselves establish Q2 readiness.

## Journal files

| Item | Correction | Prepared status |
|---|---|---|
| Main manuscript | Provide the editable format required by the journal. A separate author-produced PDF is not universally mandatory. | Word draft and PDF review copy |
| Cover letter | Requirements vary. Do not state author approval, originality or exclusive submission without confirmation. | Journal-neutral draft in Author_Completion |
| Title page | Separation and anonymization depend on review policy. | Author-completion form; identities not invented |
| Figures | Include figures that support the study; five prescribed figures are not a universal requirement. | Architecture, saved discrimination, current catalog coverage |
| Calibration figure | Requires suitable held-out predictions and a reconciled calibrator; aggregate scores cannot reconstruct a valid curve. | Not fabricated; pending analysis |
| Current LLM reliability figure | Must come from actual runs on the frozen current system; historical outcomes or regression tests are not substitutes. | Not fabricated; pending benchmark |
| Supplement | Put reproducible details and additional tables here, with genuine sources. | Draft includes S1–S4 |
| Reporting checklists | Use official applicable checklists and truthful locations/statuses. Reporting completeness is not clinical validation or absence of bias. | Two working main-item coverage maps, not final checklists |
| Highlights | Only where requested; count and length depend on the journal. | Four concise draft highlights |
| Graphical abstract | Optional unless required. Figure dimensions and format need journal review. | Conceptual draft, no unmeasured result claims |
| Declarations and forms | Actual author confirmations and institutional determinations are needed. Do not automatically declare no funding/conflicts or ethics exemption. | Author-confirmation form |
| AI assistance disclosure | Check the selected publisher's policy and describe actual assistance. | Included as an author-confirmation topic |

## Research evidence

| Item | Correction | Current treatment |
|---|---|---|
| Stage 1 baselines | Ten models are not a universal requirement. Appropriate competitive, comparably tuned baselines matter more than a fixed count. | Existing comparisons retained with split/budget caveats |
| Calibration and uncertainty | Verify reserved calibration data, identical deployed outputs and appropriate survey-design uncertainty. | Marked for repair; no new performance claim |
| Stage 2 references | Reference links do not validate every chosen threshold. Distinguish reference intervals, project policies and numerical caps. | All 39 roles documented; 30 active fields |
| Stage 3 evidence | Compare methods using identical data/rules/objectives. Separate feasibility, integrality, cost assumptions and runtime. | Historical 29-entry benchmark archived separately from current 49-entry catalog |
| Stage 4 evidence | Separate deterministic chat routing, tool/validator performance, the report compiler, and actual LLM generations. | Verified v4 aggregates separate from historical comparisons and software checks |
| Reproduction | A requirements file alone is not reproducibility. Freeze code, checkpoint, preprocessing, catalog, cases and environment; test the release. | Curated code snapshot and manifests; clean-environment release still pending |
| NFHS or other Indian cohort | Not automatically compatible with an 87-feature NHANES model. Check predictor availability, units, outcome definitions, population and access terms before calling it external validation. | No such validation claimed |
| Expert review | Whether it is optional depends on claims and the journal. Human acceptability claims need human evidence. | No completed ratings claimed |
| Trial or prospective study | Not universally needed for a computational feasibility paper; clinical effectiveness claims require suitable clinical evidence. | No benefit or intervention claim |
