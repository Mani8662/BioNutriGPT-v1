2. STREAM 1: BLOOD BIOMARKERS & LIPID RATIOS (FEATURES 1 TO 6)
================================================================================
These 6 features provide direct biochemical observation of 3-month glycemic 
memory and total circulating atherogenic particle burden. Universal, non-fasting 
assays ensure 100% genuine data integrity without synthetic lab imputation.

[Index 1]
- Code Name     : LBXGH
- Full Name     : Glycohemoglobin (HbA1c)
- Units / Range : % of total hemoglobin (Normal: 4.5–5.6%, Pre-diabetic: 5.7–6.4%, Diabetic: >= 6.5%)
- What It Is    : The percentage of red blood cell hemoglobin chemically bonded to glucose.
- Why It Is Used: Acts as a 90-120 day biological memory tape of systemic blood sugar. 
                  It is the ADA gold-standard clinical diagnostic metric for Type 2 Diabetes. 
                  Connects via a direct residual skip highway into the Diabetes prediction head.

[Index 2]
- Code Name     : LBDHDD
- Full Name     : Direct HDL-Cholesterol ("Good" Cholesterol)
- Units / Range : mg/dL (Normal: 40–60 mg/dL; High Risk: < 40 mg/dL for men, < 50 mg/dL for women)
- What It Is    : High-Density Lipoprotein cholesterol, which transports excess sterols 
                  from peripheral arterial walls back to the liver (reverse cholesterol transport).
- Why It Is Used: A protective anti-atherogenic marker. In metabolic syndrome and insulin 
                  resistance, lipoprotein lipase impairment causes HDL to plummet, signaling 
                  elevated cardiovascular and diabetic risk.

[Index 3]
- Code Name     : LBXTC
- Full Name     : Total Serum Cholesterol
- Units / Range : mg/dL (Desirable: < 200 mg/dL, Borderline: 200–239 mg/dL, High: >= 240 mg/dL)
- What It Is    : The total sum of all circulating cholesterol fractions (HDL + LDL + VLDL).
- Why It Is Used: Foundational biomarker of systemic lipid load used in Framingham and ASCVD 
                  cardiovascular risk calculations.

[Index 4]
- Code Name     : NON_HDL_CHOL
- Full Name     : Non-HDL Cholesterol (LBXTC - LBDHDD)
- Units / Range : mg/dL (Desirable: < 130 mg/dL, Moderate: 130–159 mg/dL, High: >= 160 mg/dL)
- What It Is    : All circulating cholesterol carried by atherogenic, plaque-forming particles 
                  (LDL + VLDL + IDL + Lp(a)), calculated directly by subtracting HDL from Total Cholesterol.
- Why It Is Used: Endorsed by AHA/ACC cardiology guidelines as superior to LDL for measuring 
                  atherosclerotic cardiovascular disease (CVD) risk, with zero fasting requirement.

[Index 5]
- Code Name     : CHOL_HDL_RATIO
- Full Name     : Total Cholesterol to HDL Ratio (LBXTC / LBDHDD)
- Units / Range : Dimensionless ratio (Ideal: < 3.5, Moderate Risk: 3.5–5.0, High Risk: > 5.0)
- What It Is    : The mathematical quotient of total cholesterol divided by protective HDL.
- Why It Is Used: Directly quantifies the atherogenic balance. Highly sensitive predictor of 
                  coronary artery disease even when total cholesterol appears borderline normal.

[Index 6]
- Code Name     : NON_HDL_TO_HDL_RATIO
- Full Name     : Non-HDL to HDL Ratio (NON_HDL_CHOL / LBDHDD)
- Units / Range : Dimensionless ratio (Desirable: < 2.5, High Risk: > 3.5)
- What It Is    : The ratio of total plaque-causing particles to protective scavengers.
- Why It Is Used: Isolates atherogenic particles against protective HDL. Strongly correlates 
                  with vascular endothelial plaque accumulation and arterial stiffness.

3.1 Raw Macronutrients & Micronutrients (Features 7 to 45)
--------------------------------------------------------------------------------
[Index 7]
- Code Name     : DR1TKCAL
- Full Name     : Total Energy Intake
- Units / Range : kcal/day (Typical range: 800–4,500 kcal)
- What It Is    : Total daily caloric throughput ingested from all foods and beverages.
- Why It Is Used: Foundational energy balance parameter; chronic caloric surplus is the 
                  primary thermodynamic driver of metabolic obesity and adiposity expansion.

[Index 8]
- Code Name     : DR1TPROT
- Full Name     : Total Dietary Protein
- Units / Range : grams/day (Typical: 40–180 g)
- What It Is    : Nitrogenous organic compounds essential for muscle mass, enzyme synthesis, and satiety.
- Why It Is Used: Satiety signaling and lean muscle mass preservation; modulates postprandial 
                  glucose spikes and preserves resting metabolic rate.

[Index 9]
- Code Name     : DR1TCARB
- Full Name     : Total Carbohydrates
- Units / Range : grams/day (Typical: 100–500 g)
- What It Is    : Total sugars, starches, and fiber combined.
- Why It Is Used: Primary macronutrient driver of acute postprandial glycemic excursions and 
                  hepatic triglyceride synthesis.

[Index 10]
- Code Name     : DR1TSUGR
- Full Name     : Total Dietary Sugars
- Units / Range : grams/day (Typical: 20–250 g)
- What It Is    : Monosaccharides (glucose, fructose) and disaccharides (sucrose, lactose).
- Why It Is Used: High intake promotes rapid hepatic de novo lipogenesis, visceral fat deposition, 
                  and chronic pancreatic beta-cell strain, directly driving Type 2 Diabetes risk.

[Index 11]
- Code Name     : DR1TFIBE
- Full Name     : Dietary Fiber
- Units / Range : grams/day (Adequate Intake: >= 25g female, >= 38g male; Typical: 8–40 g)
- What It Is    : Non-digestible plant carbohydrates (soluble and insoluble).
- Why It Is Used: Slows intestinal glucose absorption, blunts postprandial glycemic spikes, binds 
                  bile acids to reduce circulating cholesterol, and fosters short-chain fatty acid 
                  production by gut microbiota.

[Index 12]
- Code Name     : DR1TTFAT
- Full Name     : Total Dietary Fat
- Units / Range : grams/day (Typical: 30–180 g)
- What It Is    : The sum of all dietary lipids (saturated, monounsaturated, and polyunsaturated).
- Why It Is Used: Highest energy density macronutrient (9 kcal/g); governs total caloric density 
                  and fat-soluble nutrient absorption.

[Index 13]
- Code Name     : DR1TSFAT
- Full Name     : Total Saturated Fatty Acids
- Units / Range : grams/day (AHA Recommendation: < 6% of total calories; Typical: 10–60 g)
- What It Is    : Fatty acids with no double bonds between carbon molecules.
- Why It Is Used: Downregulates hepatic LDL receptor activity, elevating circulating atherogenic 
                  apolipoprotein-B particles and driving coronary artery disease risk.

[Index 14]
- Code Name     : DR1TMFAT
- Full Name     : Monounsaturated Fatty Acids (MUFA)
- Units / Range : grams/day (Typical: 10–70 g)
- What It Is    : Fatty acids with one double bond (e.g., oleic acid found in olive oil and nuts).
- Why It Is Used: Cardiometabolic protective lipid fraction; improves systemic insulin sensitivity 
                  and stabilizes HDL cholesterol levels.

[Index 15]
- Code Name     : DR1TPFAT
- Full Name     : Polyunsaturated Fatty Acids (PUFA)
- Units / Range : grams/day (Typical: 5–40 g)
- What It Is    : Essential fatty acids with multiple double bonds (omega-3 and omega-6).
- Why It Is Used: Reduces vascular inflammation, improves cell membrane fluidity, and lowers 
                  circulating non-HDL cholesterol.

[Index 16]
- Code Name     : DR1TCHOL
- Full Name     : Dietary Cholesterol
- Units / Range : mg/day (Typical: 50–800 mg)
- What It Is    : Exogenous sterol ingested from animal food sources.
- Why It Is Used: Modulates circulating sterol pools in hyper-responders; key feature for 
                  dietary atherogenic profiling.

[Index 17]
- Code Name     : DR1TATOC
- Full Name     : Vitamin E (Alpha-Tocopherol)
- Units / Range : mg/day (RDA: 15 mg)
- What It Is    : Fat-soluble antioxidant vitamin protecting cell membranes.
- Why It Is Used: Prevents oxidation of circulating LDL particles; oxidized LDL is the primary 
                  trigger for macrophage foam cell transformation and vascular plaque formation.

[Index 18]
- Code Name     : DR1TRET
- Full Name     : Retinol
- Units / Range : mcg/day (Typical: 50–1,500 mcg)
- What It Is    : Preformed active Vitamin A derived from animal products.
- Why It Is Used: Involved in immune regulation, vision, and cellular differentiation.

[Index 19]
- Code Name     : DR1TVARA
- Full Name     : Vitamin A (Retinol Activity Equivalents - RAE)
- Units / Range : mcg RAE/day (RDA: 700–900 mcg RAE)
- What It Is    : Combined biological activity of preformed retinol and provitamin A carotenoids.
- Why It Is Used: Systemic antioxidant defense, mucosal barrier integrity, and metabolic signaling.

[Index 20]
- Code Name     : DR1TACAR
- Full Name     : Alpha-Carotene
- Units / Range : mcg/day (Typical: 0–3,000 mcg)
- What It Is    : Provitamin A carotenoid abundant in orange and yellow vegetables (carrots, pumpkins).
- Why It Is Used: Circulating biomarker of vegetable-rich, anti-inflammatory dietary patterns; 
                  inversely associated with cardiovascular mortality.

[Index 21]
- Code Name     : DR1TBCAR
- Full Name     : Beta-Carotene
- Units / Range : mcg/day (Typical: 100–12,000 mcg)
- What It Is    : Major provitamin A carotenoid found in dark leafy greens and carrots.
- Why It Is Used: Strong antioxidant; serves as a robust proxy for raw, whole plant food consumption.

[Index 22]
- Code Name     : DR1TLYCO
- Full Name     : Lycopene
- Units / Range : mcg/day (Typical: 0–25,000 mcg)
- What It Is    : Bright red non-provitamin A carotenoid abundant in tomatoes and watermelons.
- Why It Is Used: Reduces systemic vascular oxidative stress and prevents endothelial nitric 
                  oxide degradation, protecting against arterial hypertension.

[Index 23]
- Code Name     : DR1TLZ
- Full Name     : Lutein + Zeaxanthin
- Units / Range : mcg/day (Typical: 200–10,000 mcg)
- What It Is    : Xanthophyll carotenoids found in green leafy vegetables and egg yolks.
- Why It Is Used: Protects against oxidative retinal damage and markers of subclinical atherosclerosis.

[Index 24]
- Code Name     : DR1TVB1
- Full Name     : Thiamin (Vitamin B1)
- Units / Range : mg/day (RDA: 1.1–1.2 mg)
- What It Is    : Water-soluble coenzyme essential for carbohydrate and branched-chain amino acid metabolism.
- Why It Is Used: Critical for pyruvate dehydrogenase activity; thiamin deficiency impairs glucose 
                  metabolism and worsens diabetic complications.

[Index 25]
- Code Name     : DR1TVB2
- Full Name     : Riboflavin (Vitamin B2)
- Units / Range : mg/day (RDA: 1.1–1.3 mg)
- What It Is    : Central component of coenzymes FAD and FMN required for cellular respiration.
- Why It Is Used: Essential for mitochondrial energy production and lipid beta-oxidation.

[Index 26]
- Code Name     : DR1TNIAC
- Full Name     : Niacin (Vitamin B3)
- Units / Range : mg/day (RDA: 14–16 mg)
- What It Is    : Precursor to NAD and NADP, involved in DNA repair, glycolysis, and lipid metabolism.
- Why It Is Used: Plays a pharmacological role in raising HDL and lowering very-low-density lipoproteins.

[Index 27]
- Code Name     : DR1TVB6
- Full Name     : Vitamin B6 (Pyridoxine)
- Units / Range : mg/day (RDA: 1.3–1.7 mg)
- What It Is    : Coenzyme for transamination, decarboxylation, and glycogenolysis.
- Why It Is Used: Modulates homocysteine clearance (elevated homocysteine damages vascular endothelium).

[Index 28]
- Code Name     : DR1TFOLA
- Full Name     : Total Folate
- Units / Range : mcg/day (RDA: 400 mcg DFE)
- What It Is    : Naturally occurring food folate and synthetic folic acid combined.
- Why It Is Used: Essential for single-carbon transfer reactions, DNA synthesis, and homocysteine remethylation.

[Index 29]
- Code Name     : DR1TFA
- Full Name     : Folic Acid
- Units / Range : mcg/day (Typical: 0–800 mcg)
- What It Is    : Synthetic oxidized form of folate added to fortified grains and supplements.

[Index 30]
- Code Name     : DR1TFF
- Full Name     : Food Folate
- Units / Range : mcg/day (Typical: 50–500 mcg)
- What It Is    : Reduced, naturally occurring polyglutamyl folates from vegetables, beans, and fruits.

[Index 31]
- Code Name     : DR1TFDFE
- Full Name     : Folate, Dietary Folate Equivalents (DFE)
- Units / Range : mcg DFE/day (Food folate + 1.7 * synthetic folic acid)
- What It Is    : Standardized biological availability score for total ingested folates.
- Why It Is Used: Used by dietary guidelines to assess nutritional adequacy across fortified and whole diets.

[Index 32]
- Code Name     : DR1TVB12
- Full Name     : Vitamin B12 (Cobalamin)
- Units / Range : mcg/day (RDA: 2.4 mcg)
- What It Is    : Cobalt-containing vitamin synthesized exclusively by bacteria; found in animal foods.
- Why It Is Used: Vital for nerve myelin maintenance and erythrocyte maturation; metformin medication

[Index 33]
- Code Name     : DR1TVC
- Full Name     : Vitamin C (Ascorbic Acid)
- Units / Range : mg/day (RDA: 75–90 mg)
- What It Is    : Potent water-soluble antioxidant and enzymatic cofactor for collagen synthesis.
- Why It Is Used: Promotes vascular endothelial nitric oxide bioavailability and scavenges free radicals.

[Index 34]
- Code Name     : DR1TVK
- Full Name     : Vitamin K (Phylloquinone)
- Units / Range : mcg/day (Adequate Intake: 90–120 mcg)
- What It Is    : Fat-soluble vitamin abundant in leafy green vegetables.
- Why It Is Used: Essential cofactor for matrix Gla protein, which directly inhibits arterial

[Index 35]
- Code Name     : DR1TCALC
- Full Name     : Calcium
- Units / Range : mg/day (RDA: 1,000–1,200 mg)
- What It Is    : Essential mineral for skeletal mineralization, muscle contraction, and vasodilation.
- Why It Is Used: Key electrolyte in the DASH diet; adequate calcium intake facilitates vascular

[Index 36]
- Code Name     : DR1TPHOS
- Full Name     : Phosphorus
- Units / Range : mg/day (RDA: 700 mg; Typical: 800–2,200 mg)
- What It Is    : Mineral component of bones, cell membranes (phospholipids), and ATP.
- Why It Is Used: Elevated phosphorus from processed food phosphate additives induces vascular 
                  calcification and endothelial dysfunction.

[Index 37]
- Code Name     : DR1TMAGN
- Full Name     : Magnesium
- Units / Range : mg/day (RDA: 310–420 mg; Typical: 150–500 mg)
- What It Is    : Intracellular cation cofactor for over 300 enzymatic reactions, including all ATP pathways.
- Why It Is Used: Natural calcium antagonist; critical for insulin receptor tyrosine kinase activity 
                  and vascular smooth muscle relaxation. Low intake directly promotes insulin resistance 
                  and arterial hypertension.

[Index 38]
- Code Name     : DR1TIRON
- Full Name     : Iron
- Units / Range : mg/day (RDA: 8–18 mg)
- What It Is    : Essential trace metal for hemoglobin oxygen transport and mitochondrial cytochromes.

[Index 39]
- Code Name     : DR1TZINC
- Full Name     : Zinc
- Units / Range : mg/day (RDA: 8–11 mg)
- What It Is    : Structural and catalytic cofactor for transcription factors and insulin storage crystals.

[Index 40]
- Code Name     : DR1TCOPP
- Full Name     : Copper
- Units / Range : mg/day (RDA: 0.9 mg)
- What It Is    : Trace mineral cofactor for cytochrome c oxidase and ceruloplasmin.

[Index 41]

- Full Name     : Sodium

- What It Is    : Major extracellular electrolyte governing osmotic volume and fluid retention.
- Why It Is Used: Chronic sodium overload causes intravascular fluid expansion, increases arterial wall

[Index 42]

[Index 43]

- Full Name     : Selenium
- Units / Range : mcg/day (RDA: 55 mcg)

[Index 44]

- Units / Range : mg/day (Typical: 0–600 mg)

[Index 45]

- Full Name     : Alcohol (Ethanol)
- Units / Range : grams/day (0 g if non-drinker; 14g = 1 standard drink)
- What It Is    : Psychoactive caloric substance yielding 7 kcal/gram.
- Why It Is Used: Chronic excessive intake elevates systemic blood pressure, worsens hypertriglyceridemia, 
                  impairs hepatic gluconeogenesis, and drives visceral adiposity.

3.2 Derived Clinical Nutrition Interaction Ratios (Features 46 to 52)
--------------------------------------------------------------------------------
These 7 ratios mathematically combine raw nutrients to separate diet quality 
from absolute food volume (Willett nutritional epidemiology standards).

[Index 46]
- Code Name     : PROT_PCT_KCAL
- Full Name     : Protein Percentage of Total Energy
- Formula       : (DR1TPROT * 4.0) / DR1TKCAL * 100.0
- Units / Range : % of total calories (AMDR: 10–35%; Typical: 12–25%)
- What It Is    : The fraction of total daily energy derived from protein.
- Why It Is Used: Governs satiety and lean tissue maintenance during weight loss interventions.

[Index 47]
- Code Name     : CARB_PCT_KCAL
- Full Name     : Carbohydrate Percentage of Total Energy
- Formula       : (DR1TCARB * 4.0) / DR1TKCAL * 100.0
- Units / Range : % of total calories (AMDR: 45–65%; Typical: 40–60%)
- What It Is    : The fraction of total daily energy derived from carbohydrates.
- Why It Is Used: In diabetic patients, elevated carbohydrate fractions directly increase 
                  hepatic de novo lipogenesis and insulin requirements.

[Index 48]
- Code Name     : FAT_PCT_KCAL
- Full Name     : Fat Percentage of Total Energy
- Formula       : (DR1TTFAT * 9.0) / DR1TKCAL * 100.0
- Units / Range : % of total calories (AMDR: 20–35%; Typical: 25–45%)
- What It Is    : The fraction of total daily energy derived from fats.
- Why It Is Used: Quantifies dietary energy density; elevated fat percentages contribute 
                  to passive overconsumption and metabolic obesity.

[Index 49]
- Code Name     : FIBER_PER_1000_KCAL
- Full Name     : Fiber Density per 1,000 kcal
- Formula       : DR1TFIBE / (DR1TKCAL / 1000.0)
- Units / Range : grams per 1,000 kcal (AHA Target: >= 14 g/1,000 kcal; Typical: 6–12 g)
- What It Is    : Measures the concentration of fiber relative to caloric throughput.
- Why It Is Used: Evaluates true diet quality independently of how much a person eats; 
                  differentiates high-volume nutrient-dense diets from calorie-dense processed diets.

[Index 50]
- Code Name     : SUGAR_TO_FIBER_RATIO
- Full Name     : Sugar to Dietary Fiber Ratio
- Formula       : DR1TSUGR / (DR1TFIBE + 1.0)
- Units / Range : Dimensionless ratio (Optimal: < 2.0; High Risk: > 5.0)
- What It Is    : Compares rapidly absorbed simple sugars against absorption-slowing fiber.
- Why It Is Used: Direct marker of glycemic velocity; diets with high sugar and low fiber trigger 
                  rapid postprandial glucose surges, directly driving Type 2 Diabetes risk.

[Index 51]
- Code Name     : SODIUM_POTASSIUM_RATIO
- Full Name     : Sodium to Potassium Ratio
- Formula       : DR1TSODI / (DR1TPOTA + 1.0)
- Units / Range : Dimensionless ratio (Ideal: < 1.0; Typical US: 1.2–2.5; Severe Risk: > 2.5)
- What It Is    : The balance between extracellular fluid retainer (sodium) and intracellular vasodilator (potassium).
- Why It Is Used: Far more predictive of hypertension, arterial stiffening, and stroke mortality 
                  than sodium or potassium evaluated individually.

[Index 52]
- Code Name     : SAT_TO_UNSAT_FAT_RATIO
- Full Name     : Saturated to Unsaturated Fat Ratio
- Formula       : DR1TSFAT / (DR1TMFAT + DR1TPFAT + 0.1)
- Units / Range : Dimensionless ratio (Desirable: < 0.35; High Risk: > 0.60)
- What It Is    : Compares plaque-promoting saturated fats against protective unsaturated fats (MUFA + PUFA).
- Why It Is Used: Captures dietary atherogenicity; high ratios directly correlate with coronary artery disease.

4.1 Continuous Sleep & Physical Activity Variables (Features 53 to 61)
--------------------------------------------------------------------------------
[Index 53]
- Code Name     : SLEEP_HOURS
- Full Name     : Sleep Duration
- Units / Range : hours/night (Optimal: 7.0–8.0 hours; Plausible: 3.0–14.0 hours)
- What It Is    : Self-reported average nightly sleep on weekdays/workdays.
- Why It Is Used: Both short (<6h) and long (>9h) sleep independently elevate cardiometabolic 
                  mortality, promote daytime cortisol secretion, and worsen insulin resistance.

[Index 54]
- Code Name     : SLEEP_DEV_FROM_7_5
- Full Name     : Circadian Sleep Deviation from 7.5 Hours
- Formula       : abs(SLEEP_HOURS - 7.5)
- Units / Range : hours (Optimal: 0.0; High Risk: > 2.5 hours)
- What It Is    : The absolute distance from the epidemiologically validated lowest-mortality sleep target (7.5 hours).
- Why It Is Used: Converts the classic U-shaped mortality curve of sleep into a linear mathematical 
                  penalty that neural networks can easily optimize.

[Index 55]
- Code Name     : PAD680
- Full Name     : Daily Sedentary Sitting Time
- Units / Range : minutes/day (Typical: 60–900 minutes; High Risk: >= 480 minutes / 8 hours)
- What It Is    : Minutes spent sitting or reclining at work, home, or commuting (excluding sleep).
- Why It Is Used: Sitting suppresses lipoprotein lipase activity in skeletal muscle and turns off 
                  endothelial nitric oxide synthesis, directly driving vascular stiffness and obesity.

[Index 56]
- Code Name     : PA_VIG_WORK_MIN_WK
- Full Name     : Vigorous Occupational Physical Activity
- Units / Range : minutes/week (Typical: 0–1,200 min; 0 if PAQ605 == 0)
- What It Is    : Heavy lifting, digging, or construction work that causes large increases in breathing or heart rate.
- Why It Is Used: Quantifies heavy labor energy expenditure; separates physical work from recreational exercise.

[Index 57]
- Code Name     : PA_MOD_WORK_MIN_WK
- Full Name     : Moderate Occupational Physical Activity
- Units / Range : minutes/week (Typical: 0–1,800 min; 0 if PAQ620 == 0)
- What It Is    : Brisk walking or carrying light loads at work that causes small increases in breathing.
- Why It Is Used: Measures routine occupational movement across the work week.

[Index 58]
- Code Name     : PA_WALK_BIKE_MIN_WK
- Full Name     : Active Transportation Walking / Bicycling
- Units / Range : minutes/week (Typical: 0–900 min; 0 if PAQ635 == 0)
- What It Is    : Continuous travel on foot or bicycle for at least 10 minutes to get to places.
- Why It Is Used: Non-recreational daily lifestyle mobility; inversely associated with obesity and CVD.

[Index 59]
- Code Name     : PA_VIG_REC_MIN_WK
- Full Name     : Vigorous Leisure-Time / Gym Physical Activity
- Units / Range : minutes/week (Typical: 0–600 min; 0 if PAQ650 == 0)
- What It Is    : Sports, running, intense gym workouts, or aerobics in leisure time.
- Why It Is Used: Primary stimulus for mitochondrial biogenesis, cardiorespiratory fitness (VO2 max), 
                  and robust GLUT4 insulin-independent glucose clearance.

[Index 60]
- Code Name     : PA_MOD_REC_MIN_WK
- Full Name     : Moderate Leisure-Time Physical Activity
- Units / Range : minutes/week (Typical: 0–900 min; 0 if PAQ665 == 0)
- What It Is    : Brisk walking, recreational swimming, or volleyball for leisure.
- Why It Is Used: Reaches WHO recommended physical activity minimums (150 min/week).

[Index 61]
- Code Name     : PA_TOTAL_MET_MIN_WK
- Full Name     : Total Weekly Physical Activity Volume (MET-minutes/week)
- Formula       : (PA_VIG_WORK * 8) + (PA_MOD_WORK * 4) + (PA_WALK_BIKE * 4) + (PA_VIG_REC * 8) + (PA_MOD_REC * 4)
- Units / Range : MET-min/week (WHO Minimum: >= 600 MET-min/week; Highly Active: >= 3,000)
- What It Is    : Metabolic Equivalent of Task minutes per week, integrating intensity and duration.
- Why It Is Used: Standard global benchmark integrating total metabolic energy expended through movement.

4.2 Binary Lifestyle & Activity Screening Flags (Features 62 to 67)
--------------------------------------------------------------------------------
[Index 62]
- Code Name     : SLQ050
- Full Name     : Physician-Diagnosed Sleep Trouble
- Units / Range : Binary {0 = No, 1 = Yes}
- What It Is    : Participant was formally informed by a doctor that they have a sleep disorder (e.g., insomnia, sleep apnea).
- Why It Is Used: Sleep apnea causes nighttime intermittent hypoxia, triggering daytime sympathetic surges, 
                  resistant hypertension, and elevated CVD risk.

[Index 63]
- Code Name     : PAQ605
- Full Name     : Vigorous Work Activity Screening Response

5.3 Informative Missingness Indicators (Features 84 to 88)
--------------------------------------------------------------------------------
These 5 binary flags prevent data loss and capture behavioral non-response patterns 
(the "dual-channel missingness" architecture).

[Index 84]
- Code Name     : INDFMPIR_MISS
- Full Name     : Family Income Ratio Missingness Indicator
- Units / Range : Binary {1 = Skipped/Declined, 0 = Reported}
- What It Is    : Flags that the participant declined or was unable to report family income.
- Why It Is Used: People who decline income questions often experience economic stress or instability. 
                  Allows the model to learn the risk pattern of non-responders rather than dropping them.

- Full Name     : Sleep Duration Missingness Indicator
- Units / Range : Binary {1 = Missing, 0 = Reported}
- What It Is    : Flags that sleep duration was not reported in the interview.

[Index 86]

- Full Name     : Daily Sitting Time Missingness Indicator
- Units / Range : Binary {1 = Missing, 0 = Reported}
- What It Is    : Flags that daily sitting minutes were skipped or unknown.
- Why It Is Used: Preserves patient record while flagging non-reported sedentary behavior.

[Index 87]
- Code Name     : PA_TOTAL_MET_MIN_WK_MISS
- Full Name     : Total Physical Activity Missingness Indicator
- Units / Range : Binary {1 = Missing, 0 = Reported}
- What It Is    : Flags that physical activity survey questions were partially or fully skipped.
- Why It Is Used: Differentiates verified sedentary individuals from those who simply skipped the physical activity survey.

[Index 88]

- Full Name     : General Questionnaire Missingness Indicator
- Units / Range : Binary {1 = Minor question skipped, 0 = Fully complete profile}
- What It Is    : Summary indicator capturing if any other minor lifestyle or demographic survey item was missing.
- Why It Is Used: Signals overall survey completeness and data confidence to the transformer attention pooler.

--------------------------------------------------------------------------------
7. STRICTLY FORBIDDEN / EXCLUDED COLUMNS (LEAKAGE PROTECTION)
--------------------------------------------------------------------------------
To maintain clinical validity, the following features are strictly BANNED:
1. Anthropometric Measurements (BMXBMI, BMXWT, BMXHT, BMXWAIST):
   - Definition of TARGET_OBESITY is BMI >= 30.0. Including body weight or height 
     is circular cheating that destroys machine learning validity.
2. Fasting Morning Blood Assays (LBXGLU, LBXIN, LBXTR, LBDLDL):
   - Fasting glucose, insulin, and triglycerides were excluded to ensure a 
     walk-in, non-fasting outpatient screening setting with 0% synthetic data.
3. Doctor Questionnaire Diagnoses (DIQ*, MCQ*, CDQ*):
   - Questions like "Did a doctor ever tell you that you had diabetes or heart disease?" 
     give away the ground truth target labels.
