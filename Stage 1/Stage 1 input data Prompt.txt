# TASK: Generate Clinically Valid Patient Input Data for BioNutriGPT (Stage 1 & Stage 2 Compatible)

You are a Clinical Data Scientist and Biostatistician.
Your objective is to generate synthetic, physiologically coherent patient profiles formatted specifically as inputs for the **BioNutriGPT Multi-Stage Clinical AI Pipeline** (compatible with both standalone Stage 1 and unified Stage 1 + Stage 2 inference).

---

## 1. DUAL-STAGE ARCHITECTURAL SPECIFICATIONS & CONSTRAINTS

The BioNutriGPT system operates in two distinct clinical stages:

### Stage 1: Diagnostic Multi-Task Transformer (88 Features)
Takes an input tensor of exactly **88 features** across 4 biological modalities:
1. `BIO` (6 features): Non-fasting blood biomarkers & lipid ratios
2. `DIET` (46 features): 39 daily macro/micronutrients + 7 clinical energy & interaction ratios
3. `LIFE` (19 features): Sleep duration/deviation, sedentary time, 5 WHO GPAQ physical activity domains, and smoking status
4. `DEMO` (17 features): Age, poverty ratio, education level, sex, race flags, marital status, and missingness flags

### Strict Anti-Leakage Constraints for the 88-Feature Vector:
- **DO NOT include BMI, Body Weight, or Height in the 88-feature vector.** They are strictly excluded from Stage 1 to prevent circular target leakage on Obesity (since Obesity is clinically defined as $\text{BMI} \ge 30$).
- **DO NOT include Fasting Blood Glucose, Fasting Insulin, or LDL.** The model operates exclusively in a non-fasting outpatient setting (using HbA1c, HDL, Total Cholesterol, and Non-HDL).
- **DO NOT include Patient ID (`SEQN`) or Survey Year (`NHANES_CYCLE`).**

### Stage 2: Counterfactual Prescription Engine (Clinical Anthropometric Metadata)
While Stage 1 must remain blind to anthropometrics, **Stage 2 requires the patient's physical measurements** to calculate:
1. **Basal Metabolic Rate (BMR)** via Mifflin-St Jeor:
   - Men: $\text{BMR} = 10 \times \text{weight\_kg} + 6.25 \times \text{height\_cm} - 5 \times \text{age} + 5$
   - Women: $\text{BMR} = 10 \times \text{weight\_kg} + 6.25 \times \text{height\_cm} - 5 \times \text{age} - 161$
2. **Total Daily Energy Expenditure (TDEE)**: $\text{BMR} \times \text{PAL}$ (`sedentary`: 1.20, `light`: 1.375, `moderate`: 1.55, `active`: 1.725).
3. **Safe Protein Boundary Envelope**: $[0.8 \times \text{weight\_kg}, \; 2.0 \times \text{weight\_kg}]$ grams/day.

Therefore, for every generated patient profile, you **MUST generate realistic body weight (`weight_kg`), height (`height_cm`), and activity level (`activity_level`)** alongside the 88-feature vector.

5. `CHOL_HDL_RATIO`: Total Cholesterol / HDL [MUST equal LBXTC / LBDHDD]

## 3. PHYSIOLOGICAL COHERENCE & ANTHROPOMETRIC RULES

Ensure biological consistency across both features and anthropometrics:
1. **Thermodynamic Atwater Law**: Total Calories `DR1TKCAL` must roughly equal `(4 * Protein) + (4 * Carbs) + (9 * Fat) + (7 * Alcohol)` within a +/- 5% margin.
2. **Anthropometric Consistency**:
   - For a **Healthy / Non-Obese Archetype**: Set BMI in normal range ($18.5 - 24.9\text{ kg/m}^2$). For example: Height = 176 cm, Weight = 74 kg ($\text{BMI} = 23.9$).
   - For a **Clinical Obesity Archetype**: Set BMI $\ge 30.0\text{ kg/m}^2$. For example: Height = 172 cm, Weight = 98 kg ($\text{BMI} = 33.1$).
   - Ensure Mifflin-St Jeor daily energy expenditure ($\text{TDEE} = \text{BMR} \times \text{PAL}$) roughly correlates with baseline caloric intake `DR1TKCAL`.
3. **Fat Sub-types**: `DR1TSFAT + DR1TMFAT + DR1TPFAT` must be less than or equal to `DR1TTFAT`.
4. **Cholesterol Math**: `NON_HDL_CHOL` must strictly equal `LBXTC - LBDHDD`.
5. **Physical Activity Skip Logic**: If `PAQ605 == 0`, `PA_VIG_WORK_MIN_WK` MUST be `0.0`. If `PAQ605 == 1`, `PA_VIG_WORK_MIN_WK` must be `> 0.0`. (Apply identical logic to all 5 GPAQ pairs).

## 4. DUAL-COMPATIBLE OUTPUT FORMAT (WORKS ON BOTH INFERENCE SCRIPTS)

When asked to generate patient profiles, generate diverse clinical archetypes (e.g., Profile A: High Diabetic Risk, Profile B: High Cardiovascular Atherogenic Risk, Profile C: Healthy Active Individual).

For each patient profile, provide:
1. **A Clinical Prose Vignette**: Age, sex, height, weight, BMI, activity level, health habits, and description.
2. **A Python Dictionary of Unscaled Clinical Values & Metadata**:
   ```python
   patient_data = {
       "features_88": {
           "LBXGH": 5.2,
           "LBDHDD": 56.0,
           # ... all 88 feature values ...
       },
       "metadata": {
           "weight_kg": 74.0,
           "height_cm": 176.0,
           "age_years": 42.0,
           "is_female": False,
           "activity_level": "sedentary"
       }
   }
   ```
3. **Dual-Compatible Single-File TXT Format (Ready for `patient.txt`)**:
   Format the text file with **Line 1 containing the 88 features** and **Line 2 containing the clinical metadata comment**:

   ```text
   5.2 56.0 178.0 122.0 ... [exactly 88 numbers on Line 1 separated by spaces] ... 0 0
   # CLINICAL_METADATA: weight_kg=74.0 height_cm=176.0 activity_level=sedentary
   ```

### Why This Exact Format Works on BOTH Inference Scripts:
* **Standalone Stage 1 Inference:**
  ```powershell
  python infer_bionutrigpt_stage1.py patient.txt
  ```
  `infer_bionutrigpt_stage1.py` automatically ignores lines starting with `#`, extracts the exact 88 features, and assesses disease risks with **0% anthropometric leakage**.

* **Unified Stage 1 + Stage 2 Pipeline Inference:**
  ```powershell
  python infer_bionutrigpt_pipeline_Stage_1_and_2.py patient.txt
  ```
  `infer_bionutrigpt_pipeline_Stage_1_and_2.py` evaluates Stage 1 diagnostic risk from Line 1, and **automatically extracts the height, weight, and activity level from the `# CLINICAL_METADATA:` comment on Line 2** to compute the exact Mifflin-St Jeor caloric target and safe protein envelope for Stage 2 counterfactual optimization. (Manual CLI overrides like `--weight 80` still work if passed).
